# MCPTool render-bot

Небольшой HTTP-сервис для запуска тестовых Mineflayer-ботов против **своего** Minecraft-сервера — с IP-адреса Render, а не локального. Полезно, когда антибот-плагин ограничивает число регистраций/подключений с одного IP и нужно проверить защиту с другого адреса.

## Деплой на Render

1. Запушь эту папку (`render-bot`) как отдельный git-репозиторий на GitHub.
2. На [render.com](https://render.com) → **New → Web Service** → выбери репозиторий.
3. Render подхватит `render.yaml` автоматически (Environment: Node, Build: `npm install`, Start: `npm start`).
4. В **Environment Variables** задай `RUN_TOKEN` — произвольный секретный токен для защиты эндпоинта.
5. Деплой запустится, сервис поднимется на `https://<твой-сервис>.onrender.com`.

## Использование

```bash
curl -X POST https://<твой-сервис>.onrender.com/run \
  -H "Authorization: Bearer <RUN_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
    "host": "smpqwert11-qxbu.aternos.me",
    "port": 25565,
    "version": "1.21.11",
    "count": 5,
    "delay": 3,
    "regPassword": "1212",
    "message": "Я бот для тестирования проверки на бота"
  }'
```

Ответ приходит потоково: сначала `{"status":"started",...}`, затем после завершения всех ботов — `{"status":"done","results":[...]}` с логом каждого бота (login/verify/register/final/kicked).

## Параметры запроса

| Поле          | Обязательное | По умолчанию                                    |
|---------------|--------------|--------------------------------------------------|
| `host`        | да           | —                                                  |
| `port`        | нет          | `25565`                                            |
| `version`     | нет          | автоопределение mineflayer                         |
| `count`       | нет          | `1` (максимум `20` за один вызов)                  |
| `delay`       | нет          | `3` (сек между запуском ботов)                     |
| `regPassword` | нет          | `1212`                                             |
| `message`     | нет          | `Я бот для тестирования проверки на бота`          |

## Важно

- Free-план Render засыпает после ~15 мин простоя — первый запрос после сна будет долгим (cold start).
- Используй только против серверов, которыми управляешь сам.
